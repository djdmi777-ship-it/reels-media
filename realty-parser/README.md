# Парсер объявлений недвижимости

Собирает объявления с ЦИАН, Авито и Домклик по ссылке поиска и сохраняет в XLSX/CSV
(ссылка, цена, заголовок, площадь, комнаты, этаж, адрес).

## Запуск
```bash
pip install -r requirements.txt && playwright install chromium
python parser.py "<URL поиска>" --pages 3 -o flats.xlsx
```
Фильтры (город, цена, комнаты) выставь на сайте в браузере и скопируй URL страницы поиска.
Можно передать несколько URL разных сайтов сразу; дубли убираются.

## Статус сайтов
- **ЦИАН** - работает (~28 карточек на страницу).
- **Авито** - работает, но при частых запросах отдаёт 429: бери `--pages` небольшим, делай паузы.
  Поле `address` захватывает рядом стоящий текст (метро, рейтинг).
- **Домклик** - закрыт антибот-защитой Qrator, из облака отдаёт пустую страницу.
  Попробуй `--headed` на своём компьютере; гарантий нет.

Парсинг может нарушать правила сайтов: используй умеренно, для личных целей.

## Сканер новых объявлений (Анапа и район)
`scanner.py` каждые 30 минут (GitHub Actions, `.github/workflows/anapa-scan.yml`) сравнивает выдачу с базой
виденных ссылок и шлёт новые в Telegram. Поиски лежат в `searches.json`.

Секреты репозитория (Settings -> Secrets and variables -> Actions):
- `TG_BOT_TOKEN`, `TG_CHAT_ID` - Telegram;
- `AVITO_PROXY_URL` - `http://user:pass@host:port`, российский домашний/мобильный прокси. Нужен только для
  Авито: с адресов GitHub он отвечает 429. Без секрета Авито в облаке пропускается, ЦИАН работает напрямую.

### Управление поисками из Telegram
Команды `/add <ссылка> [название]`, `/list`, `/remove <номер>`, `/help` (модуль `tgbot.py`).
Сканер в начале каждого запуска забирает сообщения бота и выполняет команды только от `TG_CHAT_ID`.
Актуальный список поисков хранится в `state/searches.json` (кэш Actions), `searches.json` - стартовый.
Новый поиск первый раз сканируется «тихо», уведомления идут только о новых объявлениях.
Лимит поисков - `MAX_SEARCHES` (по умолчанию 20). Памятка для клиента: `ПАМЯТКА_КЛИЕНТУ.md`.

Расписание: каждые 30 минут с 07:00 до 22:30 МСК (экономия 2000 бесплатных минут приватного репозитория).
Тесты без сети: `python test_tgbot.py`. Локально настройки можно положить в `.env` (см. `.env.example`).

### Трафик
ЦИАН грузится в «лёгком» режиме (без картинок, шрифтов, скриптов и стилей - карточки есть в HTML), ~0,5 МБ
на страницу. Авито без скриптов не показывает выдачу и чаще блокирует, поэтому у него «экономный» режим:
скрипты Авито грузятся, а реклама, аналитика, картинки, шрифты, капча и фоновые запросы Яндекс Браузера - нет.
Страницы блокировки (403/429/«Доступ ограничен») сразу закрываются, не скачивая скрипты.
Кэш браузера хранится в профиле (`state/browser/avito-yandex/DiskCache`) и переживает запуски.
В логе печатается реальный трафик по сети (`реально по сети`) и число ответов из кэша;
в тестовых запусках из ветки (`TECH_REPORT=1`) это же приходит владельцу в Telegram.
Расчёт: ГБ/мес ≈ МБ за проверку × проверок в день × 30 / 1024.
Переключатели: `NO_BLOCK=1` - грузить Авито целиком, `NO_JS=1` - без скриптов (не рекомендуется).

### Авито по кругу
`AVITO_PER_RUN` - сколько поисков Авито проверять за запуск (по очереди); `0` - все сразу (сейчас так:
мобильный прокси со сменой IP справляется).
