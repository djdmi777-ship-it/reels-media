# Парсер объявлений недвижимости

Собирает объявления с ЦИАН, Авито и Домклик по ссылке поиска и сохраняет в XLSX/CSV
(ссылка, цена, заголовок, площадь, комнаты, этаж, адрес).

## Запуск
```bash
pip install -r requirements.txt && playwright install chromium
python parser.py "<URL поиска>" --pages 3 -o flats.xlsx
```
Фильтры (город, цена, комнаты) выставь на сайте в браузере и скопируй URL страницы поиска.
Можно передать несколько URL разных сайтов сразу; дубли убираются.

## Статус сайтов
- **ЦИАН** - работает (~28 карточек на страницу).
- **Авито** - работает, но при частых запросах отдаёт 429: бери `--pages` небольшим, делай паузы.
  Поле `address` захватывает рядом стоящий текст (метро, рейтинг).
- **Домклик** - закрыт антибот-защитой Qrator, из облака отдаёт пустую страницу.
  Попробуй `--headed` на своём компьютере; гарантий нет.

Парсинг может нарушать правила сайтов: используй умеренно, для личных целей.
