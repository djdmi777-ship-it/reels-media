# Как пользоваться ботом

Бот сам проверяет Авито и ЦИАН примерно каждые 30 минут (с 7:00 до 23:00 по Москве)
и присылает новые объявления: цена, название, адрес, ссылка. Уже присланное не повторяется.

## Добавить поиск
1. Откройте Авито или ЦИАН в браузере, выберите регион, категорию и фильтры (цена, комнаты и т.д.).
2. Скопируйте ссылку из адресной строки.
3. Отправьте боту: `/add ссылка название` - например
   `/add https://www.avito.ru/anapa/kvartiry/prodam Квартиры Анапа`

При первой проверке бот запомнит объявления, которые уже есть, и напишет «Поиск подключён».
Дальше будут приходить только новые.

## Другие команды
- `/list` - список ваших поисков с номерами
- `/remove 2` - удалить поиск №2
- `/help` - подсказка

Команды применяются при ближайшей проверке, то есть ответ может прийти в течение 30 минут.
