# ai-content-bot

Контент-проект: рилсы и офферы с AI-моделями (сгенерированные девушки) для продажи услуги
«контент без съёмок» брендам и магазинам белья/одежды.

## Инструменты
- Скиллы лежат в репозитории (`.claude/skills/`) и подхватываются в каждом чате:
  `ghost-editor` (монтаж talking-head рилсов), `motion-design` (моушн-дизайн кодом: HTML + Playwright + ffmpeg),
  `lemo-opuscar` (короткие фильмы в 40+ стилях; библиотеку сам качает в `~/lemo-opuscar`).
- Системные зависимости (ffmpeg 9, Python-пакеты, Whisper, библиотека lemo-opuscar) живут в контейнере
  и пропадают между чатами. Если их нет: `bash scripts/install-video-tools.sh` (полная установка ~30 мин;
  ffmpeg 9 ставится в `~/.local/bin`, этот путь должен идти первым в PATH).

## Ролики (`reel-ai-models/`)
- Движок: один HTML с canvas и `window.seek(t)`, рендер `render.py` (Playwright → JPEG-кадры → ffmpeg).
  Исходники видео (`src/`) и кадры (`frames/`) в git не лежат: их нужно заново скачать или прислать.
- `reel3.html` — «Сколько из них настоящих?», трек Darkside «A1» (154 BPM, дроп 130.87 с).
  Финал: `deliverables/ai-models-reel-v3.mp4`.
- `reel4.html` — светлый лукбук-оффер для магазинов белья и одежды, трек Mixkit «Cat Walk» #371
  (130 BPM, дроп 14.769 с). Финал: `deliverables/lookbook-stores-offer.mp4`.
- Рендер v3: `HTML=reel3.html OUT=out3 BEATS=76 python3 render.py chunk k 3` (k=0..2), затем `encode`.
  Для v4 добавить `BEATS=60 BPM=130 TAIL=0.6 MUSIC=src/catwalk.mp3 SONG_DROP=14.769`.

## Модели (одна модель встречается в нескольких клипах)
1: morning (кровать), laundry (стиральная машина), unbox (распаковка) · 2: dress (бал), yoga ·
3: beach, fire (камин) · 4: makeup, lace (бельё у окна) · 5: selfie (полотенце).
Не выдавать разные клипы одной модели за разных девушек.

## Правила, которые просил пользователь
- Без тряски камеры на бит и без «шторок»: чистые склейки в бит, плавный наезд.
- Модель всегда видна в кадре (не резать на полосы, не терять голову).
- Обнажёнку в ролики не брать. В финале мелко: «модели созданы нейросетью».
- Сначала сценарий и стоп-кадры, потом полный рендер.
